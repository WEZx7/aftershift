How AFTERSHIFT Works

Investigate incidents instead of blindly choosing answers. Tickets, messages, device records and alerts may only reveal part of the story.

  1. Read the incident carefully.
  2. Inspect related systems and records.
  3. Use the Terminal to uncover hidden evidence.
  4. Review your Evidence Board.
  5. Contain threats when enough information is available.
  6. Make the final decision based on verified evidence.

Terminal Basics

Every chapter contains its own investigation commands. Type help inside the Terminal to see commands available during that shift.

help Show commands available in the current chapter.
status Review current system and investigation status.
evidence List evidence discovered during the current case.
clear Clear the investigation terminal.

Signal Colors

GREEN

Verified, healthy or successfully contained.
YELLOW

Suspicious, incomplete or requires investigation.
RED

Critical, malicious or identity cannot be trusted.

Evidence

Evidence may be discovered through multiple paths. A Terminal command, message inspection or incident decision can reveal the same clue.

The strongest endings usually require more than high system statistics. You need the correct evidence and the correct final decision.

Mobile Controls

AFTERSHIFT is fully playable on mobile. Rotate to landscape if you want more room for the Terminal and investigation panels.

Terminal commands are not real operating-system commands. Everything runs inside the game simulation.

Getting Stuck

Check the current chapter's investigation tips and type help in the Terminal. Command names usually correspond to suspicious identifiers visible elsewhere in the interface.
